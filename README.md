# 911 GT3 · Configurador 3D

Borrador de configurador 3D futurista (Three.js):

- Cambio de color de pintura y acabado (brillo / metalizado / mate)
- Tintado de vidrios (de transparente a oscuro total)
- Suspensión regulable (modo pista y front lift)
- Color de pinzas de freno, escenario neón con auto-giro
- Botón para cargar cualquier otro modelo `.glb`

## Modelo 3D
`modelo.glb`: "Porsche 911 GT3" por **Outlaw Games**, licencia
[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) (Sketchfab).
Uso no comercial: para un proyecto final de pago hay que sustituirlo por un modelo con licencia comercial.

Las piezas cuyo material se llame `paint` y `window`/`glass` se conectan a los controles de pintura y vidrios.
